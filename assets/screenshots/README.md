## Capture tips

- 브라우저 배율은 90–100% 정도로 맞춥니다.
- 계정명, Subscription ID, Resource ID, 이메일 등 개인/조직 식별 정보는 가립니다.
- 중요한 지표나 Reason이 한 화면에 들어오도록 크롭합니다.
- 16:9 또는 가로형 비율을 권장합니다.
- 스크린샷을 교체하면 README의 이미지가 자동으로 갱신됩니다.
